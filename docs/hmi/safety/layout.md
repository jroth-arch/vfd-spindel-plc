# S4 - SAFETY layout

Obrazovka pro prvni pohled na safety stav a alarmy.

## Bloky

- Velka signalka bezpecnosti a citelny duvod stavu z `Safety.StatusText`.
- `Pohon povolen`, `Bezpecnostni okruh v poradku`, `Porucha aktivni` a `Kod poruchy`.
- Alarmy lozisko/kartac/teplota/vibrace.
- Fyzicke DI: relay AUX, E-Stop, external fault.
- Text duvodu poruchy a nav konfigurace.

## Barvy

- V PORADKU zelena, BLOKOVANO oranzova, PORUCHA cervena.
- Text bezpecnostniho stavu a kod poruchy pouze Output.
