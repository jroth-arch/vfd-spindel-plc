# S7 - NASTAVENI TESTU layout

Servisni obrazovka pro nastaveni testu a synchronizaci casu. Musi byt chranena prihlasenim.

## Bloky

- Dva panely se shodnym nazvem `NASTAVENI TESTU`.
- Levy panel: tlacitko `Synchronizovat cas`, stav synchronizace a posledni uspesna synchronizace.
- Pravy panel: maximalni teplota loziska, maximalni teplota kartace, prumer krouzku, perioda sinu, maximalni proud a verze PLC.
- Stav synchronizace: `V PORADKU` zelene nebo `NTP SERVER NEDOSTUPNY` cervene.
- Posledni synchronizace: datum a cas posledni uspesne synchronizace; bez uspesne synchronizace `NENI K DISPOZICI`.
